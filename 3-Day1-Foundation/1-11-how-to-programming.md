# MicroPythonのプログラミングの方法

MicroPythonでは、PC上で開発してマイコンへ転送する方法と、マイコンと直接対話しながら実行する方法の大きく4つのスタイルがあります。

## 1. コードの作成・転送方法（4つのスタイル）

1. **ターミナルからREPLで直接入力・実行**
   * Tera Term などのシリアルターミナルを使い、対話環境（REPL）の `>>>` プロンプトへ1行ずつコマンドを入力して動作確認を行います。ちょっとした実験やピン操作のテストに最適です。
2. **PC上のエディタで作成し、REPLへ貼り付け（Copy & Paste）**
   * 普段使いのテキストエディタ（VS Code やメモ帳など）でコードを作り、シリアルターミナルへ貼り付けて実行します。複数行のコードを貼り付ける際は、REPLの**ペーストモード（`Ctrl+E` で開始、`Ctrl+D` で実行）**を使うとインデント崩れを防げます。
3. **PC上のIDE（統合開発環境）で作成・転送・実行**
   * **Thonny** や **VS Code（MicroPico拡張機能など）** を使い、PC上での編集からマイコンへのファイル転送、実行までを1つの画面で行います。初心者にも扱いやすい方法です。
4. **PC上のエディタで作成し、CLIツールで転送**
   * エディタで保存した `.py` ファイルを、コマンドラインツール（公式の **`mpremote`** や `ampy`、`rshell` など）を使ってマイコンのファイルシステムへ転送します。スクリプト化や自動化と相性が良い方法です。

---

## 2. プログラムの実行方法

作成したプログラムをマイコン上で動かす方法は、大きく2通りあります。

1. **メモリ上で一時実行する（電源を切ると消える）**
   * ターミナルのREPLで直接コードを入力して実行する、またはIDEの「実行（Run）」ボタンを押して実行する方法です。マイコン内のストレージには保存されないため、リセットすると消えます。
2. **マイコン内のファイルシステムに保存して実行する**
   * マイコン内部のフラッシュメモリに `.py` ファイルとして保存する方法です。
   * **手動実行（`import`）:** `test.py` などの名前で保存し、REPL上で `import test` と入力して呼び出します。
   * **自動実行（`main.py`）:** ファイル名を **`main.py`** にして保存すると、電源投入時やリセット時に自動で実行されます（PCと切り離して単体動作させるときに使います）。

---

## 3. MicroPythonの起動シーケンス

マイコンに電源が投入（またはリセット）されると、MicroPythonは以下の順番で処理を行います。

1. **`boot.py` の実行（存在する場合）**
   * 起動時に最初に1回だけ実行されます。Wi-Fiの初期接続やシステム設定など、環境整備用のプログラムを記述するのに適しています。
2. **`main.py` の実行（存在する場合）**
   * `boot.py` の完了後、自動的に実行されます。センサーの計測やLED制御など、メインのアプリケーション処理をここに書きます。
3. **REPL（対話モード）へ移行**
   * `main.py` が終了すると（無限ループ `while True:` を書いていない場合）、シリアルコンソールに `>>>` が表示され、キーボードからの入力待ち状態になります。

> **💡 ヒント（`main.py` が止まらないとき）**
> `main.py` に無限ループを書いた状態で自動実行されると、REPLの入力待ちに戻らなくなります。その場合は、ターミナル上で **`Ctrl+C`** を押すとプログラムを強制停止してREPLに戻ることができます。
