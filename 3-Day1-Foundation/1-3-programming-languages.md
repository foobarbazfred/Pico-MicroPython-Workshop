### プログラミング言語

マイコン用のプログラミング言語は、プログラムの実行方法によって大きく次のように分けられます。

| 分類 | 実行方法 | 主な特徴 | 長所 | 短所 |
|---|---|---|---|---|
| コンパイル型 | パソコンなどでソースコードをコンパイルし、マイコン用の実行形式を作成して転送する | 実行時にインタプリタを必要としない | 高速、メモリ使用量が少ない、リアルタイム制御に向いている | コンパイルや書き込みが必要、デバッグの手順が多い |
| インタプリタ型 | マイコン上のインタプリタがソースコードを読み取りながら実行する | ソースコードを転送してすぐ実行できる | 開発・修正・実験が簡単、対話的に試せる | 実行速度が遅くなりやすい、インタプリタ分のメモリが必要 |
| 仮想マシン型 / バイトコード型 | ソースコードを中間形式に変換し、マイコン上の実行環境で動かす | コンパイル型とインタプリタ型の中間的な方式 | 移植性と実行速度のバランスがよい | 実行環境が必要、対応するマイコンが制限されることがある |

### 主な言語・開発環境の比較

| 言語・環境 | 分類 | 特徴 | 向いている用途 |
|---|---|---|---|
| C | コンパイル型 | マイコン開発で最も基本的な言語の一つ。実行速度が速く、ハードウェアを細かく制御できる | 小規模な組み込み機器、ドライバ、リアルタイム制御 |
| C++ | コンパイル型 | Cの高速性に加えて、クラスやテンプレートなどの機能を利用できる | 高機能な組み込み機器、Arduino、ライブラリを利用した開発 |
| Arduino | C++を基盤とした開発環境・フレームワーク | 初期化や入出力の処理を簡単に書ける。サンプルやライブラリが豊富 | 電子工作、センサー制御、初心者向けの試作 |
| Embedded Rust | コンパイル型 | Rustのメモリ安全性を活用できる。実行速度も速い | 安全性が重要な機器、比較的大規模な組み込み開発 |
| TinyGo | コンパイル型 | Go言語を小規模マイコン向けに対応させた処理系 | Go言語の経験を活かした組み込み開発 |
| C# | 実行環境・仮想マシン型が中心 | .NET系の実行環境を使って動作させることができる | .NETやC#の経験者によるIoT機器開発 |
| Embedded Java | 仮想マシン型 | Javaの実行環境をマイコン上に搭載して動かす | Java知識を活かした機器開発 |
| MicroPython | インタプリタ型 | マイコン上にPythonインタプリタを搭載し、ソースコードを転送して実行できる | 教育、電子工作、センサー実験、短期間の試作 |
| CircuitPython | インタプリタ型 | MicroPythonから派生した、教育・電子工作向けの環境。USBメモリのように扱えるボードもある | 初心者向け教材、Adafruit製品、手軽なプロトタイピング |
| Lua | インタプリタ型 | 軽量なスクリプト言語。組み込み機器に組み込みやすい | 設定スクリプト、軽量な制御、組み込み用途 |
| JavaScript / TypeScript | インタプリタ型またはバイトコード型 | 対応するランタイムが必要。TypeScriptは通常JavaScriptに変換してから実行する | IoT、ネットワーク連携、Web技術者が参加する開発 |
| Blockly | ビジュアルプログラミング環境 | ブロックを組み合わせてプログラムを作る。実際にはPythonやJavaScript、Arduinoなどへ変換することが多い | プログラミング教育、初学者向け教材、簡単な制御 |

### 使い分けの目安

| 目的 | 向いている言語・環境 | 理由 |
|---|---|---|
| 高速処理や正確なタイミング制御 | C、C++、Rust | 実行速度が速く、ハードウェアを細かく制御できる |
| 電子工作を簡単に始めたい | Arduino | 情報、入門書、サンプル、ライブラリが多い |
| 学習や短期間の試作をしたい | MicroPython、CircuitPython | コンパイルせずに修正・実行でき、対話的に試せる |
| Adafruit製品を手軽に使いたい | CircuitPython | 対応ボードや教材が充実している |
| メモリや電力が限られている | C、C++、Rust | インタプリタを搭載する必要がなく、少ない資源で動作させやすい |
| 安全性を重視したい | Rust | メモリ安全性をコンパイル時に検査できる |
| ビジュアルに学習したい | Blockly | ブロックを組み合わせて処理の流れを理解できる |
| 既存のJava、C#、Goの知識を活用したい | Embedded Java、C#、TinyGo | 既存の言語知識や開発環境を活用できる |

### まとめ

マイコン向けのプログラミング言語は、基本的には「コンパイル型」と「インタプリタ型」に分けられます。

- コンパイル型は、実行速度が速く、制御が細かい反面、コンパイルや書き込みが必要です。
- インタプリタ型は、開発が簡単で、試行錯誤しやすい反面、実行速度やメモリ使用量に制約が出ます。

また、ArduinoやBlocklyは「言語」そのものというより、開発環境やフレームワークとして扱われることが多いです。

このため、マイコン開発では「どの言語を使うか」だけでなく、「どの環境で開発するか」も重要な選択になります。

### 参考

- ArduinoはC++をベースにした開発環境であり、電子工作で広く使われている
- MicroPythonやCircuitPythonは、マイコンにPythonの実行環境を載せて簡単に動かすことができる
- CircuitPythonはAdafruit社が推進しており、教育や電子工作の分野で人気がある
- ブロック型のBlocklyは、プログラミング初心者にとって理解しやすい表現手段となる
