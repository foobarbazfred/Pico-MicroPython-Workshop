# マイコンを使ってどのようなシステムが試作できるか


<img src="assets/tech_apl_map2.png" width=80%>

I2CやSPI等のインタフェースを介してマイコンとセンサを接続、さらに表示装置、CMOSカメラ等と接続することでいろんなシステムを実現することができます。また、Raspberry Pi Pico 2WはWi-Fiを介してインターネットと接続できますので、ネットワーク経由で遠隔監視や遠隔操作も可能になります。どのようなデバイスを接続できるのか、どのようなシステムを試作できるのか簡単に整理します。

1. マイコンとセンサを接続する（環境・動き・状態を知る）
   - 室内環境モニタ（温湿度・気圧・CO2など）：一定間隔で測定し、しきい値を超えたらLEDやブザーで知らせるシステム
   - 姿勢・傾き・動き検知ロガー：加速度・ジャイロセンサを使い、モノの動きや振動のパターンを記録・判定するプロトタイプ
   - 照度・距離連動の自動照明／アラート：明るさや接近を検知して、ランプの点灯や通知のトリガーにする装置
2. マイコンとディスプレイを接続する（数値を「見える化」）
   - スタンドアロン小型ステータス表示器：キャラクタLCDや小型OLEDに、センサ値・カウント・動作モードを表示する卓上デバイス
   - 簡易デジタル時計・タイマー／カウントダウン装置：ボタン操作と組み合わせて、作業タイマーや経過時間表示器として動かすプロトタイプ
   - インタラクティブな操作パネル（メニュー・設定表示）：ロータリーエンコーダやボタンと画面を組み合わせ、設定値を変えられる小型コントローラ
3. マイコンとストレージ接続（SDカード）を接続する（データを蓄積）
   - フィールド／長期データロガー：CSVやログ形式でセンサデータをSDカードに保存し、後からPCの表計算や分析ツールで読み込むシステム
   - 設定ファイル・プリセット読み込み装置：閾値や動作パターンを外部ファイルとして持ち、コードを変えずに挙動を切り替えるプロトタイプ
   - 音声・画像アセットの保持：効果音データや表示用データをSDカードに置き、必要に応じて呼び出す構成
4. マイコンとCMOSカメラを接続する（映像・画像を取り込む）
   - 定点撮影・インターバルカメラ：一定時間ごとやボタン押下・センサ反応をきっかけに画像を保存・転送する装置
   - 簡易監視・変化検知プロトタイプ：取得した画像やフレームの変化をもとに、対象の有無や動きを捉える仕組み
5. マイコンをネットワークと接続する（遠隔とつながる、クラウドのソリューションを借りる）
   - ブラウザから見られるWebダッシュボード／簡易Webサーバ：スマホやPCのブラウザからセンサ値を確認したり、画面上のボタンでLEDやサーボを動かしたりするプロトタイプ
   - MQTTを使った Pub/Sub 連携システム：センサ値をトピックに配信し、別の機器やダッシュボード、自動化フローと疎結合につなぐ構成
   - Web API・クラウド連携デバイス：外部の天気・通知・AIなどのAPIを呼び出したり、クラウド側へデータを送って記録・可視化したりするシステム
   - 外部AI・PC連携の視覚入力ノード：マイコン側で画像を撮影し、PCやクラウド側の画像認識・解析処理へ渡すエッジ側の試作
