# Raspberry Pi Pico 2 WとMicroPythonを用いた研修資料一式

## セミナー概要
- MicroPython と Raspberry Pi Pico 2 W を用いて、センサや周辺機器の制御方法、簡単なシステムの試作方法を学びます
- 本研修は座学ではなく、ブレッドボードとマイコン、センサを使って実際に回路を組みます
- 基礎編と実践編の2日間コースで構成されます
  - 1日目は基礎編で、MicroPythonとセンサー類等の接続方法、簡単なセンサーアプリの作り方を学びます
  - 2日目は実践編で、チームに分かれて作りたいアプリを設計から実装まで行います(アドバイス付きの、もくもく会のような)。各チーム単位で成果を報告します。工夫した点や大変だった点、気づき、面白さを皆さんと共有してください
## 本セミナーを通して学べること
- マイコン、MicroPython、センサ類を活用した教材作りのヒント
  - MicroPythonによるマイコン制御  
  - マイコンとセンサを組み合わせた試作方法
  - IoTシステムに適用できるプロトタイプ開発
