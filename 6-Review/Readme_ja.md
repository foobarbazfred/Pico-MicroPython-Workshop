# レビュー記録
### このページは、ワークショップ用テキストの改善取り組みをメモしています（修正を管理するページ(本来は裏側のドキュメント)）
1. 基本的な誤り（記載揺れ、バグ）の一覧化と対応管理
2. 章立て分かりにくい点の改善（文書構造見直し）
    - 必修項目、選択項目、演習等の明文化
3. 追記必要な項目（書かないと問題になる点への対応）
4. 理解しやすくするための改善理解しやすくするための改善（加えた方がよい努力目標）
   - 回路図の追加
   - 定数や条件文の説明
   
### なお、対応が完了した改善点は課題リストから消します（残っているとどれが未対応か分からないので）

### Claudeとの対話で得たビジョン

AI時代に、あえて集まって手を動かす2日間
1. 実物を動かして確かめる。サンプルコードをAIが提示してくれるが、例えばLEDの明るさや点滅の早さ、機構が面白いかどうか、実機でしか知りえない
1. 直面する課題や失敗から問題の原因究明に進む。配線？、コード？、部品？ etc。。。仕様通りに動かない理由を自分の手で突き止める
1. 人と一緒に作る。意見交換したり、自分の考えをまとめたり、調整しながら、一つの試作を作る。他のメンバの取り組みや成果物を聞いて学びにつなげる
